# Code of conduct

## Our promise

We want this project to be a friendly place for everyone. We expect good behavior from all contributors, in issues, pull requests, discussions and any other project space.

## Expected behavior

- Be respectful and kind.
- Accept feedback on your work. Give feedback on the work, not on the person.
- Assume good intent. Ask a question if something is not clear.
- Help others to learn.

## Unacceptable behavior

- Harassment, insults, threats or discrimination of any kind.
- Personal or political attacks.
- Publishing the private information of others without permission.
- Any other conduct that is not appropriate in a professional setting.

## Enforcement

The maintainers can edit or remove comments, close issues and pull requests, and block people who do not follow this code.

To report a problem, use the private reporting channel of this repository, or contact a maintainer through their profile. The maintainers keep reports private.

## Scope

This code applies in all project spaces. It also applies when a person represents the project in public.
